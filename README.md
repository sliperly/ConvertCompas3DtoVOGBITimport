# ConvertCompas3DtoVOGBITimport
Конструктора тратят очень много времени на внесение данных об изделиях в производственную систему VOGBIT. 
При этом вся необходимая информация содержится в разработанных 3Д-моделях и её можно конвертировать в файл Excel с помощью инструмента Отчёты. 
А у VOGBIT есть инструмент загрузки из файла Excel. Проблема - эти файлы разные. Нужен конвертер.
Загрузить номенклатуру из Excel это здорово. Но кто же загрузит номенклатуру в Excel!?
Если есть изделие разработанное в Компас, то как информацию о нём занести в Vogbit?
Моя лень довела меня до использования всяческих еретических продуктов на базе ИИ, не к ночи они будут помянуты.
Процедуру работы с чатботами объяснять не буду - даёте задачу, получаете кусок кода, запускаете, читаете сообщения 
об ошибках, ошибки, которые поняли правите сами, которые не поняли формулируете в новом запросе.
Базовый смысл моего пути. У Компаса есть инструмент, который может сохранить структуру изделия, со всей внутренней информацией, в виде файла Excel. 
Делается через Управление > Отчёты > Редактор свойств. А уже этот файл можно переписать в вид пригодный для загрузки в Vogbit. 
Название файла должно быть таким же как я использовал или дорабатывайте скрипт. 
Файл Excel из Компаса перед обработкой надо переконвертировать в более современный формат.
Сразу скажу, что выложенный мной скрипт Windows недоработанный и подходит только под привычный для меня формат. 
Но желающие и нуждающиеся смогут воспользоваться концепцией.
Скрипт кидается в папку с сохраненным из Компаса файлом Excel, где уже должны лежать файлы Excel шаблонов Vogbit. 
И желательно рядом должны быть папки с файлами разработанного изделия. 
По логике скрипт должен взять данные из определённых строк исходного файла и записать в файлы шаблонов, 
а попутно прочитать названия файлов, которые надо подгрузить в Vogbit и включить их пути для подгрузки в фалйы шаблонов.
